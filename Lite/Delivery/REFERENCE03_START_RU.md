# FinRate Lite — выбранный дизайн, 0.2.1 / work-reference03

Этот пакет возвращает оформление первоначального интерактивного образца: графитовые карточки, шапку «FinRate Lite / Меню», общий переключатель разделов и синюю кнопку «Доход».

`site/` содержит уже собранные файлы приложения. Программирование и npm не требуются. Перед размещением сохраните резервную копию нужных тестовых данных.

Существующий тестовый адрес: https://kqh2rnnnmm-dot.github.io/finrate-lite-test/. Он относится к отдельному репозиторию finrate-lite-test. Этот пакет на сайт ещё не загружался. Нельзя заменять им основной finrate/Full.

После загрузки содержимого site/ на тестовую площадку откройте её в Safari. Проверьте «Меню → Настройки»: внизу должна быть версия0.2.1/work-reference03. При обновлении0.2.0 используется та же новая тестовая база, без сброса. Данные старой парольнойtest01 по-прежнему не переносятся автоматически.

Если показывается старое оформление, сначала закройте вкладки и установленную Lite, затем откройте сайт снова. Не очищайте данные сайта ради обновления: это может удалить локальные данные. Существующая установленная PWA и фактическое HTTPS-обновление ещё требуют проверки.

Проверка: главный экран; «Меню» и возврат; выбор категории из расхода; «Отчёты → тип → параметры → Показать отчёт»; live-ползунок и вопрос над карточкой после сохранения. Данные в показе чата вымышленные и не сохраняются в вашу базу.

Вход без пароля/PIN сохранён. Пароль создаётся только для экспортируемой защищённой копии. Публикация не выполнена; физический Safari/iPhone не проверен.

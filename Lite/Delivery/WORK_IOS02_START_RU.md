# FinRate Lite 0.2.0 — проверка нового дизайна

В Work подготовлена новая сборка без регистрации, пароля и PIN. При первом запуске укажите начальный остаток; при следующем открытии приложение откроется сразу. База новая, прежние защищённые данные не удаляются.

## Быстро посмотреть здесь

Интерактивный вариант в ответе показывает те же компоненты с вымышленными данными. Его изменения действуют только до перезагрузки демонстрации. Это отдельный режим просмотра, а не ваша финансовая база.

## Пакет для телефона

В каталоге `site/` лежит уже собранное приложение: index.html, app.js, app.css, иконки, manifest и SW. Код редактировать и npm запускать не требуется.

Разместите СОДЕРЖИМОЕ `site/` в отдельном тестовом HTTPS-сайте тем же способом, которым размещали предыдущую Lite. Не загружайте весь внешний архив вместо сайта, если площадка ожидает index.html в корне. Full не заменять. Эта работа сама сайт не публиковала; нового адреса пока нет.

После размещения откройте адрес в Safari на iPhone → «Поделиться» → «На экран „Домой“» → «Добавить». Для проверки новой сборки откройте «… → Настройки» и найдите внизу `0.2.0 · work-ios02`.

Если обновляете прежний тестовый адрес, сначала сохраните копию старой базы, затем закройте прежнюю Lite и её вкладки Safari. Повторно откройте адрес после загрузки новой сборки. Если остался старый дизайн, не очищайте данные сайта: это может удалить старую базу; сначала проверьте версию и обновление SW. Более безопасно проверить новый пакет на отдельном тестовом адресе.

Пароль при запуске не нужен. В «Настройки → Данные и копии → Сохранить копию» пароль задаётся только для экспортируемого файла. Старую поддерживаемую зашифрованную копию можно открыть через «Восстановить копию» с её прежним паролем или ключом.

## Что проверить на iPhone

1. Главная не гуляет влево-вправо; заголовок закреплён. История прокручивается внутри списка.
2. «Расход»: сумма, дата, одна строка категории, заметка. Откройте категорию, выберите подкатегорию и вернитесь — сумма/заметка сохранились.
3. «Конверты → Покупки → Доля дохода»: движение меняет рубли. Отпустите — вопроса ещё нет. Нажмите «Сохранить» — вопрос над карточкой.
4. «Отчёты»: сначала выбор. Откройте «Расходы», задайте период/группировку/фильтры, затем «Показать отчёт». Вернитесь к параметрам.
5. «… → Внешний вид»: светлая/тёмная темы. Вернитесь по стрелке, убедитесь, что открываются отдельные экраны.
6. Закройте и откройте приложение: нет регистрации или PIN, тестовые операции сохранились. Сохраните копию и проверьте восстановление в отдельном чистом тестовом профиле.

Можно загрузить вымышленный пример через «Настройки → Данные и копии → Загрузить пример». Это заменяет только новую тестовую базу после подтверждения; предварительно сохраните нужные данные.

Chromium-проверка пройдена. Настоящие Safari/iPhone и HTTPS-размещение в этой работе не проверялись. Перезапуск браузера не заменяет резервную копию.

# G1: роли цвета и проверка контраста

Источник — [оригинальный референс владельца](REFERENCE_PALETTE.jpeg), точные шесть кодов утверждены в задании: #06141B, #11212D, #253745, #4A5C6A, #9BA8AB, #CCD0CF. Это одна глобальная палитра, не шесть отдельных тем. Настройки `appearance` и `colorPalette` независимы; финансовые `theme/topPalette/bottomPalette` не перепрофилированы.

| Роль | Цветная светлая | Цветная тёмная |
|---|---|---|
| Canvas / theme-color | #CCD0CF | #06141B |
| Карточка, диалог, меню, сообщение | #E7EBEA (осветлённая производная для иерархии) | #11212D |
| Поле, мягкая поверхность, выбранное/keyboard-состояние | #CCD0CF | #253745 |
| Остров / dock | #9BA8AB с 95% непрозрачностью | #11212D с 95% непрозрачностью |
| Основной текст | #06141B | #CCD0CF |
| Вторичный текст / placeholder | #253745 | #9BA8AB |
| Различимая граница поля | #4A5C6A | #9BA8AB |
| Тени прежней геометрии | Прозрачности #4A5C6A | Прозрачности #06141B |

Не используется обычный текст #CCD0CF на #4A5C6A: около 4.45:1. #4A5C6A используется в границах, декоративных тенях и образце, не как такая текстовая пара. При prefers-reduced-transparency острова непрозрачны, маска canvas без полупрозрачного перехода. Размеры, шрифты и геометрия D1 прежние.

## Обоснованные семантические исключения

Фирменная синяя кнопка и её белый текст, опасные фоны, финансовые цвета sand/plum/olive сохранены. На более тёмном светлом острове исходные семантические подписи потребовали более тёмных производных **того же смысла**:

| Текстовый токен | Цветная светлая | Цветная тёмная |
|---|---|---|
| Ссылка/синее действие | #003568 | прежний #9BC3FF |
| Расход/опасный текст | #701B27 | прежний #FF858D |
| Доход | #084526 | прежний #78D5A2 |
| Перевод | #483605 | прежний #EBCB71 |
| Кредитный долг | #4F256B | прежний #D8B6F0 |

Значения и цвета двух финансовых показателей Главной не заменены этой палитрой. Тип/подпись операции и иконки сохраняются: смысл не передаётся только цветом. Focus остаётся штатным заполнением + подчёркиванием; disabled — прежним неактивным состоянием, не финансовым статусом. Никаких дополнительных белых рамок.

## Измерение

Browser-тест читает **вычисленные CSS-цвета**: 7 текстовых ролей × 6 поверхностей + две пары белого текста на action/danger-action = 44 пары на схему. Прозрачность острова компонуется с canvas. Для цветной схемы каждая пара обязана быть ≥4.5:1; тест включает оба движка. Дополнительно Chromium проверяет те же пары с реальным media override prefers-reduced-transparency и opaque-островом. Точный минимум и файлы измерений — [TEST_REPORT](TEST_REPORT.md).

Нейтральные токены не исправляются побочно. Их полный диагностический набор включает условные пары, не обязательно используемые вместе (опасное выбранное меню использует danger-selected). Он не означает сертификацию всех унаследованных состояний. Неизменность нейтрального оформления подтверждается сравнением снимков основных экранов одного browser/runtime; Settings и новое содержание FAQ исключаются из побайтового сравнения контента.

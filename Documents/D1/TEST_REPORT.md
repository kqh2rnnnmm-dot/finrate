## Адаптация существующих тестов

Утверждённые изменения D1 потребовали обновить ожидания: прямой #home-configure теперь есть; details для 5–6 разрешён; внутри note-field есть штатный toolbar; ожидаемый build — d1-ui01. Финансовые unit assertions не менялись.

В ходе прогона исправлены тестовые предположения: outside-click выбирает реальную точку вне нового верхнего chooser, а не старый центр кнопки баланса; измерение Home ожидает кадр ResizeObserver/rAF, а не промежуточный DOM; проверка отсутствия записей при тестировании доступности сравнивает ciphertext после намеренно сохранённой настройки стороны меню. Для самого приложения дополнительных изменений после фиксации итоговой сборки не потребовалось. Результаты не объявляются успешными по старым логам другого HTML; SHA приложения проверяется при завершении.

## Ограничения и безопасность

В браузерах использованы только одноразовые профили и вымышленные базы. Настоящий профиль владельца, его финансовая база и копии не открывались/не сбрасывались. Никаких сетевых API/аналитики, новой схемы, финансовой механики или G1/A1–A3 нет. 39 из 52 src-файлов побайтно прежние; app.mjs меняет только build ID.

Нативные Safari/PWA, клавиатура, accessory-панель и VoiceOver на iPhone в этой среде не проверены. Модель VisualViewport и WebKit/Linux — дополнительные проверки геометрии/движка.

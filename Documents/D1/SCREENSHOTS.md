# D1: снимки до/после

Все снимки созданы на вымышленных данных. «До» — публичные файлы main `46d21be`; «после» — `d1-ui01`. Оригинальные шесть изображений владельца изучены, но не публикуются вместе с кодом. Изображения с `keyboard-model` показывают **модель VisualViewport**, без настоящей клавиатуры iPhone. Реальное iOS accessory-поведение проверяется отдельно.

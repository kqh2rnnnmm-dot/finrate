# Корректирующий C1: карта представлений и ввода

Тип поверхности задаётся существующим ui.sheet: явный mode имеет приоритет; формы/textarea по умолчанию large, отдельные короткие сценарии явно compact. Новые параллельные стеки или редакторы не созданы. Типы существующих вызовов не менялись.

| Сценарий | Представление | Общий ввод / действие корректировки |
|---|---|---|
| Отдельное поле суммы/имени/примечания | large field-editor | grid/одна область текста, непрозрачный фон, общая клавиатура |
| Чтение note/comment | large note-viewer | прежний read-only, отдельное Редактировать, общая изоляция |
| Создание/изменение операции, возврат, продолжение черновика | large форма | focus + field-editor, guard и финансовый save прежние |
| Дополнительно операции | compact список команд | сохраняется; выбранное поле открывает отдельный large |
| Новый счёт из операции/дохода, счёт/кошелёк, переименование/остаток | large формы | generic enhancer/field-editor, прежний возврат к источнику |
| Кредитная политика, распределение долга, части расхода | large формы/выборы по прежним вызовам | общий enhancer; расчёты/лимиты не меняются |
| Категории/подкатегории, переименование/объединение | large формы и wizard | прежний shared field-editor, исходные команды и маршруты |
| План дохода: мастер/проверка/сумма/имя/comment | large формы; отдельные короткие решения сохраняют явный compact | один field-editor; прямой тест просвечивания вложенной суммы |
| Закрыть поступление/остановить план | существующие формы large | тип не менялся, comment наследует textarea enhancer |
| Настройки/FAQ/история/безопасность | основной main или large по прежнему вызову | общая visual isolation; PIN/пароли исключены из enhancer |
| Выбор вида операции, dirty/draft/negative confirmations | существующий explicit compact | геометрия и механика не превращаются в fullscreen |
| Долгое нажатие / context-menu | custom surface overlay | прежние hold/drag/release/cancel; изоляция native parent сохраняется |
| Native select/date и боковой вызов | нативный контроль / прежний launcher | новых панелей/переключателей не создано |

Реальные поля ввода: суммы расходов/доходов/переводов/комиссий/погашений, кредитные части; примечания операций/возвратов/черновиков; названия/описания счетов; категории/подкатегории; сумма/имя плана и comment закрытия. Они проходят через focus.textValue либо createFieldEditor.enhance. Полей заметки в категории/самом плане не добавлено. Новых длинных полей настроек нет; существующие select/toggle и protected security inputs работают прежним способом.

Изменены только style.css, surfaces.mjs, chrome.mjs; app — build ID, help — FAQ. Вызывающие field-editor/focus/ui/navigation/management/planning/split/credit не переписаны. Сам исходный field-editor уже был общий, причина исправляется в его CSS и инфраструктуре поверхностей.

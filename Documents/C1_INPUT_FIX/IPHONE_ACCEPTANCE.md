# Корректирующий C1: проверка на настоящем iPhone

Сборка c1-input02. Пока не проверена на устройстве. Chromium и Playwright WebKit/Linux с моделью VisualViewport не являются проверкой Safari/PWA iOS.

Проверять в Safari и установленной PWA, обе темы, портрет/альбом, обычный/увеличенный текст. Только вымышленные записи. Не очищать текущую базу и не восстанавливать реальные копии. Ветка не публиковалась; способ установки исправленной сборки требует отдельного согласования.

1. Открыть примечание операции, нажать Редактировать, ввести 500 символов с абзацами, повторными пробелами, длинным словом и буквальным HTML. Поле заполняет ширину и область над клавиатурой; скролл только текста. Перейти к началу/концу, поставить курсор касанием, поправить середину. Строка ввода видна.
2. Скрыть клавиатуру штатной кнопкой iOS. Затем повторно коснуться текста: курсор ставится в выбранное место. Текст/черновик прежние. В начале заметки короткий свайп вниз скрывает клавиатуру; при пролистанном тексте свайп продолжает прокрутку. Выделение/копирование и долгий нажим не должны превращаться в закрытие.
3. Коснуться свободного неинтерактивного места у счётчика. Клавиатура скрывается, заметка не сохраняется. После скрытия поле расширяется. Ничего не должно сохраняться только от blur, поворота или ухода в фон.
4. Настройки → Финансовое планирование → Добавить доход → Сумма. При клавиатуре нет видимой строки Финансового планирования, стрелки или скроллбара предыдущего экрана. Закрыть/снова открыть клавиатуру; повернуть устройство. Заголовок/Готово/Отмена остаются доступны, пустых полос со старым интерфейсом нет.
5. Повторить суммы расхода, дохода, перевода/погашения, комиссии, частей разделённого расхода; названия счетов/категорий/подкатегорий, описания счетов, комментарии планов и кредитные поля. Существующие значения корректны, числа не сокращаются. При выходе родительская форма и её скролл восстанавливаются.
6. Проверить Отмена → Продолжить / Не сохранять / Сохранить, сохранение родительской формы, чтение заметки без клавиатуры и отдельное Редактировать. При возврате из фона несохранённый текст сохранён. Полноэкранные формы изолированы; короткие подтверждения и контекстное меню остались прежними.
7. Проверить safe-area/notch/индикатор Домой, большие заголовки/суммы, VoiceOver, работу системной панели над клавиатурой. Нашей дублирующей панели нет. Контроль: финансовые итоги до/после редактирования текста прежние; черновик не проводит деньги.

Ограничение: WebKit PWA не предоставляет переносимого API интерактивного перетаскивания клавиатуры как в Apple Notes. Реализовано надёжное дискретное скрытие через blur только при коротком pull-down на верхней границе текста, либо тапом по свободному месту. Плавное следование клавиатуры за пальцем не заявляется.

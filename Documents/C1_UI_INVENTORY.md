## C1-NOTES-01: все реальные места

| Экран/поле | Полный просмотр | Редактор/фиксация | Проверка |
|---|---|---|---|
| Расход/доход/перевод/возврат: Дополнительно → note | Непустое поле открывает общий viewer; пустое — редактор | focus.textValue → общий editor; изменение в черновике до сохранения операции | c1-browser (расход, доход, перевод, возврат); существующие формы/финансовые регрессии; единый вызов advanced для всех видов |
| Карточка операции, включая поиск и историю счёта | Компактная кнопка Просмотреть | note-only app.mutate(operation.edit); суммы/распределения/сроки не меняются | c1-browser: ciphertext readback + totals equality |
| Продолжение черновика операции | Тот же advanced и viewer | Родительский draft/operation guard сохранён | navigation-upgrade + forms; общая реализация |
| Создание счёта/кошелька, в том числе из операции/дохода: note | Общий enhancer textarea, непустой текст → viewer | Изменение поля формы до сохранения счёта | forms/b11; общий enhancer |
| Изменение счёта: note | Тот же enhancer | Возврат текста в исходное textarea; отдельное сохранение счёта | c1-browser, account form |
| Карточка счёта (включая архив) | Компактная кнопка Просмотреть | note-only app.mutate(account.edit) | c1-browser account |
| Закрыть ожидаемый доход: comment | После ввода повторное открытие → viewer | Общий editor, затем явное Закрыть поступление | b11-browser + c1-browser |
| Сохранённый comment закрытого дохода | Проверка плана → существующие непустые комментарии → viewer | Меняется только comment; skipped/date/amount сохранены | c1-browser saved skip comment |
| История: note до/после операции/счёта/черновика | Компактная кнопка → общий viewer | Исторический снимок только читается; текущий объект открывается существующей командой | c1-browser history + history-browser; сквозной механизм notes.preview/view |

Категории/подкатегории, сами планы дохода, политики кредита, Платежи/Цели/Отчёты не имеют самостоятельных полей заметок. Новые поля не добавлены. Плановая история по прежнему скрыта; список существующих комментариев в проверке плана не включает события финансовой истории.

Никакая пользовательская база не открывалась и не очищалась. Тесты reset/security работают только с независимыми синтетическими browser contexts на localhost. Финансовые и защитные исходники контролируются C1_BASELINE_SHA256.json.

# P3 — финансовая матрица

Сборка p3-goals01 / 0.3.13-p3. Все числа ниже — вымышленные; суммы в документе хранятся целыми копейками. Канонические postings/totals, расходы/refund, B1-кредитки, P1.2 и P2 не переписывались.

## Единственные источники сумм

- Факт счёта C выводится из прежних операций. Резерв R — сумма allocate минус release/use, отдельно по каждому настоящему дебетовому счёту. Это виртуальное назначение, не движение банка.
- Новое выделение ≤ max(0, C счёта − все ещё выделенные резервы счёта). Два резерва не могут заново назначить те же деньги. Кредитные счета как источник запрещены.
- «Накопить сумму»: прогресс = доступные ещё выделенные резервы этой цели. «Профинансировать покупку или событие»: те же резервы + актуальные целые связанные покупки − действительные связанные возвраты. Один факт имеет одну активную связь, внутри покупки категории не распределяются по нескольким целям.
- Если счёт не покрывает все назначения, нельзя доказать покрытие конкретной цели без произвольного распределения дефицита. R остаётся прежним, прогресс затронутой цели показывает «Проверить покрытие», рекомендации нет. Никаких молчаливых уменьшений, отката факта или обещания физического отделения денег.
- Осторожное «Свободно» использует существующую формулу: C − все R − непогашенные обязательства горизонта за вычетом их явного покрытия теми же R. Покрытие ограничено остатком конкретного обязательства; непризнанное/недостаточное покрытие не обещается. В деталях «Свободных денег» чистая часть обязательств после покрытия резервами должна быть подписана явно; полный остаток каждого обязательства виден в списке сроков. Будущие доходы участвуют только в прежних прогнозных режимах B1, не в прогрессе цели.
- Стабильные связи: payment:ID экземпляра P1.2 и debt:ID долга P2. Только явный выбор. Для платежа должен совпадать счёт; смена/отсутствие счёта даёт предупреждение и нулевое признанное покрытие. Для P2 счёт шаблона не угадывается: реальный repayment-out проводится со счёта резерва. Динамические кредитные лоты не связываются.

## Изменения и отмены

Активная связь целой покупки остаётся доказуемой при изменениях суммы и возвратах: прогресс каждый раз выводится из текущего канонического факта. Нельзя поделить одну покупку между несколькими резервами/целями. Указанная сумма «Из резерва» может быть меньше целой покупки — остальное нового расхода должно помещаться в свободную часть того же счёта. Для уже проведённой истории нет повторного денежного движения.

После отсоединения остаётся прошлое использование, а покупка больше не входит в текущий прогресс; повторное выделение денег только явно. После закрытия цели текущие покупки/refund пересчитываются, снимок при закрытии остаётся неизменным. Просмотр не создаёт событий.

Рекомендация: остаток / число календарных месяцев от текущего до месяца срока включительно, округление вверх до копейки. Без срока, при прошедшем сроке или неопределённом покрытии рекомендация не выдумывается. Она не создаёт план, операцию, резерв или прогнозные пополнения; план пополнений — открытое расширение P5.

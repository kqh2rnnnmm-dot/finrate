# P3 — фактически реализовано

Основа: main 3add5d9c1bf4fe74c46f2609884d8527682aa9e4, принятый P2. Ветка codex/p3-goals-reserves. Сборка p3-goals01 /0.3.13-p3. Не объединено и не опубликовано.

- В существующей вкладке «Цели» работают «Мои цели» /«Резервы», текущие/архив, обе разновидности целей, срок, заметка500, точные суммы, шкала и явное завершение/отмена.
- Самостоятельные и связанные с одной целью резервы на дебетовых счетах. Выделить/освободить без канонических операций, проверка доступной части конкретного счёта, предупреждение нехватки и явное разрешение расхождения.
- Использовать: новый expense через общий редактор либо привязать существующий действительный факт. Один факт/одна активная связь; для явно связанного обязательства — прежние confirmPayment или repayDebt, без дублирующего движения. Платёж открывается через прежний payments-ui.pay/paymentForm, с сохранением названия, категорий и значений по умолчанию.
- Сумма из резерва подтверждается отдельно от полной суммы покупки. Целая покупка, включая её категории, относится к одной цели; несколько целей/резервов на факт не распределяются скрыто.
- Реальные исправления, отмены/refund пересчитывают прогресс, не пополняют резерв. Связи и история остаются, недопустимая смена счёта требует явного отсоединения. Противоречивые active/detached-флаги и повреждённые ссылки отклоняются при restore.
- Цель не закрывается при100%. Остаток при закрытии либо освобождается виртуально, либо остаётся отдельным резервом по выбору. Архив, текущие факты и снимок закрытия не смешиваются.
- Проверены ссылки сохранённых черновиков P3: отсутствующие цель/резерв/факт отклоняются до seal/CAS и при проверке копии. Новый черновик создания по-прежнему допускается без ещё не созданного root. У закрытой цели заметка доступна для чтения, без неработающего действия редактирования.
- Подпись чистого вычета обязательств при R>0: «Не покрыто резервами». Полный долг не выдаётся за уже уменьшенный; без R сохраняется прежняя подпись. Формула не меняется.
- Прежний прогноз получает persisted reserves через существующий seam. Явное покрытие одного непогашенного обязательства не даёт двойного вычета; конфликт счёта/срока/покрытия виден.
- Главная показывает реальные «Резервы» и явно выбранную цель через прежний редактор блока. Поиск, long press/context, формы/Back/позиция, явные зашифрованные черновики и общая история переиспользованы.
- Optional goals.version1 и goalId плитки внутри прежнего SCHEMA5. A2 знает только эти новые поля и точные счётчики. Криптография, IDB/service/CAS, backup1, DEK/слоты/PIN/пароль не изменены.
- Подтверждённый общий дефект: прямое скачивание копии через app.run сохраняло disabled на повторно используемом dock. finally теперь снимает блокировку оставшихся подключённых кнопок также после успешной перерисовки. Регрессия воспроизведена в обоих движках и проверяется перед offline reload.
- Новая геометрия ограничена [data-goals-ui], использует peer/group-токены и существующие поверхности/цвета. Старые CSS-правила/палитры, navigation/surfaces/field-editor не переписаны.

План пополнений P5, кредитка-источник, динамические кредитные лоты и распределение покупки между целями не реализованы; безопасные границы описаны в OPEN_ITEMS.md. Физический iPhone остаётся OPEN.

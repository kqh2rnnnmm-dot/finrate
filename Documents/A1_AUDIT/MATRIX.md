# Матрица A1: 16 обязательных сценариев

Все PASS относятся только к указанным Node/Chromium-прогонам 03.11.2026. Аппаратная колонка не считается пройденной. Источник статусов: [service/crypto JSON](../../Source/evidence/a1-audit/service-crypto-audit.json), [браузер JSON](../../Source/evidence/a1-audit/browser-audit.json), [SW](../../Source/evidence/a1-audit/service-worker-upgrade.json), [49 существующих тестов](../../Source/evidence/a1-audit/existing-49.tap).

| № | Сценарий | Результат и доказательство | На iPhone |
|---|---|---|---|
| 1 | Богатая новая база → файл → полный состав | PASS A1-01/B01: 3 счёта, 7 операций, кредит/возврат/план/категории/черновик/G1; полный JSON равен | Не проверено |
| 2 | Полная потеря локальной базы, независимый профиль | PASS A1-02/B03: два новых пустых профиля, без удаления настоящего профиля | Safari/PWA не проверены |
| 3 | Пароль и recovery; неверные секреты | PASS A1-01/02/03, B01/02/03: оба законных способа, ошибка без записи | Проверить оба способа |
| 4 | Усечение, подмена, размер, неподдерживаемый формат | PASS A1-03: 13 отказов без записи; **F06/B09**: большие корректные файлы ниже лимита ошибочно отвергаются; **F04**: null — TypeError | Большой файл/порог WebKit не проверены |
| 5 | До замены: структура/расшифровка, превью только читает | PASS A1-04/B02/B04; **F03**: проверен выбранный слот, не второй | Не проверено |
| 6 | Отмена на каждом этапе | PASS B02: пустой выбор, выбор с вводом/отбрасыванием, готовое превью; ввод после ошибки сохранён | Системный file picker требует устройства |
| 7 | Замена, подтверждение, safety и атомарность | PASS A1-05/07, B04: подтверждение обязательно, прежний шифротекст точен, rollback | «Файлы»/повторное открытие не проверены |
| 8 | Устаревшая вкладка | PASS A1-06/B05: STALE, новая запись и safety не меняются | Две вкладки Safari не проверены |
| 9 | Квота, прерывание, перезапуск, повтор | PASS A1-07/B04/06/07: 3 стадии ошибок, reload проверки, закрытие во время транзакции; один явный retry. **F05**: сообщение квоты общее | Реальный диск/выключение не проверены |
| 10 | Совместимые старые / неподдерживаемые будущие | PASS A1-08: простые схемы 1–4 → 5, без записи до изменения; B1 integration: R30 сохранён до миграции. Future format отказ | Произвольные архивные файлы не проверены |
| 11 | Локальный PIN / привязка устройства | PASS A1-05/B03/04 + security unit: PIN и none удалены при restore, локальный ключ не экспортирован | Перезапуск/Files handoff не проверены |
| 12 | Секреты после lock/reopen, артефакты | PASS A1-01/B08 и unit: финансовый UI очищен, секреты не в URL/history/storage/cache; отчёты без raw-secret | iOS snapshots, клавиатура/менеджер паролей не проверены |
| 13 | Реальный download / честный UX | PASS B01: событие download и корректный файл, приложение просит проверить сохранение. **F01**: испорченная запись может экспортироваться без проверки пригодности | Физическое наличие в «Файлах» не подтверждено |
| 14 | Холодный офлайн, запуск, SW upgrade | PASS B03 при сохранённом кэше оболочки + 15 upgrade-сценариев текущего прогона | Вытеснение кэша/установка/жизненный цикл iOS не проверены |
| 15 | Финансовые итоги и сущности | PASS A1-01/B01/03/04: JSON exact, totals, creditSummary, все 5 forecast; 8 B1 integration тестов | Ручное сравнение итогов |
| 16 | Старые копии / смена секрета | PASS A1-10 + security unit: старая копия/старый пароль, новая/новый, recovery. **F02**: DEK сохраняется и не отзывается старым паролем | Старые секреты хранить отдельно, проверить на вымышленной базе |

Состояния «PASS» и «FINDING» могут сосуществовать в одном требовании: нормальный сценарий работает, а отдельная граница требует исправления. Инъекция QuotaExceededError не равна заполнению физического диска; закрытие страницы не равно аппаратному сбою питания.

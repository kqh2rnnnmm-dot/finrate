## Предлагаемое дополнение FAQ по фактическому поведению

**Что нужно для восстановления?** Отдельный целый защищённый файл и основной пароль, действовавший при его создании, либо recovery. PIN не заменяет ни файл, ни эти секреты и не переносится вместе с копией.

**Как проверить файл без замены базы?** В «Данные и синхронизация» выбрать файл и секрет, дождаться превью, затем выбрать «Оставить без изменений». База не меняется. Для проверки другого способа повторить с другим секретом. Заголовок «Копия проверена» сейчас относится только к выбранному пути открытия.

**Сообщение о готовности означает, что файл уже есть в «Файлах»?** Нет. Выберите место и проверьте наличие самостоятельно. Текущий экспорт ещё имеет известные ограничения F01/F06; на этапе аудита они не исправлены.

**Смена пароля защищает старые копии новым паролем?** Нет: прежний файл остаётся прежним. Более того, сохранённый DEK не меняется, поэтому известная старая копия вместе со старым секретом не считается отозванной способностью расшифровки будущего тела при доступе к нему. Это требует отдельной политики, не нового обещания безопасности.

**Помогут страховочные версии при удалении PWA?** Они лежат в том же браузерном хранилище и могут исчезнуть вместе с базой. Нужен отдельно сохранённый файл. Если потеряна и оболочка приложения, сначала требуется интернет для её загрузки.

**Что уже исправлено A1?** Пока ничего в действующем приложении: выполнен аудит, созданы проверки и подготовлен адресный план. Программирование следующего этапа ожидает согласия.

# P5 — открытые границы

[PR №15](https://github.com/kqh2rnnnmm-dot/finrate/pull/15) **открыт, не слит**. Публикации нет; настоящий iPhone не проверен.

1. Реальный iPhone Safari/PWA, системные клавиатура/Files/VoiceOver/фон и ранее отложенные аппаратные A2–P4/ACCESS A остаются OPEN. Исторический A2/WebKit PIN timeout не закрывается новым Linux-прогоном.
2. В P3 нет самостоятельного включаемого плана пополнений целей. P5 показывает отсутствие таких планов и не превращает рекомендацию в обязательство. График/повторение/паузы/источник денег требуют отдельного решения владельца; независимый прогноз реализуется без них.
3. P2 не сохраняет счёт будущего возврата. Его нельзя угадывать из исходной выдачи, частичного возврата или счёта резерва. Общий прогноз может учесть известный срок/тело, но достоверный результат по счёту требует уточнения в будущей согласованной механике.
4. У существующих кредитных лотов известен кредитный счёт, но не источник будущего погашения. Используются прежние сроки/суммы B1; выписка не выдумывается. Не вводится новое распределение банковского минимума по лотам. Неизвестный срок остаётся неизвестным.
5. Ещё не проведённая покупка кредиткой не имеет канонического факта/нового лота погашения. P5 показывает ограничение точного денежного прогноза; виртуальный кредитный план/проценты/минимумы не создаются. Дополнительный гипотетический расход поддерживает дебетовые счета. Это безопасная граница симуляции, не изменение реальной кредитной модели.
6. `all` — реальные долги без календарного конца, поэтому «Что, если…» с новым гипотетическим расходом доступно только в month/m2/m3/m4. Будущие бесконечные услуги/поступления в all не включаются.
7. Неполученное просроченное поступление не имеет новой даты получения. В P5 оно показано с исходным сроком и просьбой уточнить; дата «сегодня» не назначается автоматически. Старые B1-режимы остаются побайтно прежними, включая их прежнее поведение ожиданий.
8. P6, экспорт отчётов, сохранение сценариев и ACCESS B не реализуются. Apple/Google/passkeys/CloudKit/облака отложены на неопределённый срок и не являются блокером P5.

9. npm audit: прежние 3 low +4 moderate dev/build advisories, 0 high/critical; зависимости не менялись, force-fix не применялся. Первичный JSON сохранён. Это не «чистый audit».
10. Playwright WebKit setOffline дал internal error движка. Отдельно проверен настоящий отказ TCP всего локального origin: кэшированный холодный запуск, прогноз/сценарий и отказ некэшируемого браузерного fetch. Фоновый SW update в WebKit может оставаться pending; это не объявляется доказанным быстрым исходом update. Нативный авиарежим/Files/фон iPhone остаются аппаратной проверкой.
11. Кодовый откат — к base SHA выше, без нового формата/миграции P5. Он не отменяет реальные финансовые действия, которые пользователь отдельно совершил после обновления; для возврата финансового состояния нужна собственная проверенная внешняя копия. Пользовательские копии в GitHub не создавались.

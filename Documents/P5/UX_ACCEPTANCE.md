# P5 — UX-приёмка

Рабочая ветка `codex/p5-full-forecast`; не слито и не опубликовано. Настоящий iPhone OPEN. Используются прежние панели, списки, поля суммы/даты, денежная типографика, цвета и токены FinRate.

| Сценарий | Критерий |
|---|---|
| Отчёты | Рабочий вход «Прогноз», без P6-заглушек действий и шестой вкладки |
| Начальный прогноз | Фактический остаток отдельно, прогноз остатка/ожидаемо свободно и явный период; будущие поступления не выданы за факт |
| Сводки | Расходы/поступления/пополнения целей свёрнуты, сумма/даты/число событий доступны; неизвестность подписана |
| Счета | Свёрнутая доступность по счетам; неизвестный плательщик не превращается в точный конечный остаток другого счёта |
| Причина риска | Первая дата, конкретный счёт и исходное обязательство; для одного дня честная неопределённость порядка |
| Резервы/цели | Реальные назначения и связи, без второго вычета. Нет несуществующего плана пополнений; открываются существующие карточки/форма цели |
| Источники | Платёж/долг/кредит/доход/резерв/цель используют прежние экраны. Back сохраняет период, раскрытие и внутреннюю прокрутку |
| Контекст свободных | Переход из действующего расчёта и обратно. Повторная петля к уже открытому прогнозу переиспользует его через captureReturn |
| Что, если… | Один существующий будущий event + один дополнительный дебетовый расход. Общий редактор суммы, точные копейки, native date/account, ползунок не урезает поле |
| Сравнение | «Сейчас по плану» / «Если изменить», пересчёт сразу, короткая причина/риск; нет проводки или кнопки сохранения сценария |
| Отмена/lifecycle | Back/закрыть/фон/блокировка/cold reload/bfcache убирают весь сценарий, включая прерванный общий редактор; нет черновика |
| Геометрия | 320/375/390/402/430, landscape 844×390, desktop 1280×900; 2 темы ×2 палитры, крупный шрифт. Деньги локально прокручиваются целиком, страница не расширяется |
| Доступность | Native buttons/select/details, label для полей, названный progress/slider, текстовое состояние вместо одного цвета; реальные VoiceOver и клавиатура iPhone отдельно OPEN |

P5 — надстройка над внесёнными данными, без обещания банковских гарантий. Главная не получает длинного прогноза и обычной вертикальной прокрутки. Сценарий не создаёт планов целей, переводов между счетами, кредитных лотов или облачных данных.

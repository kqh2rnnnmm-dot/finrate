# P5 · фактически реализованные изменения

Кандидат `p5-forecast01 /0.3.16-p5`, ветка `codex/p5-full-forecast`, от `aad52c592c34858122844b5b439727318b9e4bcc`. PR для ревизии; merge/deploy не выполняются. Физический iPhone OPEN.

1. Существующая вкладка «Отчёты» открывает «Прогноз»: фактический остаток отдельно, ожидаемый итог и ожидаемо свободно, календарный период, короткая причина риска. Расходы/поступления/пополнения целей/резервы/счета/уточнения раскрываются внутри той же панели.
2. `full-forecast.mjs` читает прежний B1 forecast и канонические платежи, кредитные лоты, долги, поступления и резервы. События с устойчивыми исходными ID не сохраняются в документ. Проверяются первая дата и конкретный счёт нехватки; положительный конец не скрывает ранний дефицит. Поступление и выплата в один день не имеют гарантированного порядка.
3. Покрытие явным резервом учитывается один раз. Кредитный лимит не деньги; «Мне должны» только ожидание. Планы/лимиты/цели не создают новых фактов. Неизвестные сроки/счета и переменные суммы обозначены явно, без фиктивной даты/нуля.
4. Временный «Что, если…»: одно будущее событие (сумма/дата) и один дополнительный расход с дебетового счёта. Общий редактор суммы, нативные даты/список счетов, точные копейки и ползунок. Точное поле не ограничивается ползунком. Сравнение плана/сценария и причин риска пересчитывается сразу.
5. Сценарий существует только в RAM: закрытие/Back/фон/блокировка/reload/bfcache убирают его вместе с незавершённым общим редактором. Нет mutate, проводок, revision, истории, IndexedDB write или черновика.
6. Переходы к прежним карточкам платежа/долга/кредита/дохода/резерва/цели/перевода, контекст «Свободных денег» и Back сохраняют период, раскрытие и позицию. Повторный переход переиспользует уже открытый прогноз.
7. Только локальная геометрия `[data-forecast-ui]`: компактный первый экран, без уменьшения денежных шрифтов; WebKit native select не расширяет страницу длинным названием. Главная и общие поверхности не переделаны.
8. Новые 54 unit/integration, browser/upgrade проверки, строгий baseline исходников/старых asserts и совместимая сборка из семи публичных файлов. Отчёты/FAQ/контрольная точка обновляются по реальным результатам.

**Новые исходные модули:** `full-forecast.mjs`, `forecast-ui.mjs`. **Точные hooks:** `ui.mjs` (Reports/карточки/Back), `planning-ui.mjs` (контекстный переход), `app.mjs` (route/build/persisted pageshow clear), `help.mjs` (FAQ), `style.css` (только scoped P5). Сборка/верификация/release runner и новые тесты обновлены адресно; package/lock — версия и test scripts, зависимости прежние.

**Не изменены:** прежние финансовые ядра, пять B1-режимов, dashboard/home-config, операции/P1/P2/P3/P4, сервис/store/crypto, reset/PIN/password/ACCESS A, общие focus/surfaces/navigation/редакторы. SCHEMA=5, finrate-backup/1. Нового поля документа или миграции нет. Подробное SHA-доказательство в delivery-final.json.

**Не реализовано:** P6, новый график взносов в цели, сохранение сценариев, симуляция новых кредитных лотов/неизвестных выписок, Apple/Google/OAuth/passkeys/CloudKit/облако. Это явные границы задания, [OPEN_ITEMS](OPEN_ITEMS.md).

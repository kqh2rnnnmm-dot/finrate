# P1.2 — фактические изменения

Основа main `4ac42ea024d5676a0e0d076b235b90b57d4f970c` (P1.1/PR9 объединён). Ветка `codex/p1-2-payments-extended`; сборка `p1-2-payments01`, версия `0.3.11-p1.2`. P1.2 ещё не принят; аппаратная приёмка A2/A3/P1.1/P1.2 открыта.

| Раздел задания | Реализация |
|---|---|
| Переменные | По умолчанию полная оплата; финальный расход закрывает период по реальному итогу, включая 1700/2300 вместо2000. Части600+1100 дают1700, не фиктивный остаток300. Будущий ориентир прежний |
| Неизвестный итог частей | Компактный выбор: полная оплата либо явное уточнение суммы периода через существующий редактор. Частичные факты всегда меньше уточнённой оценки; скрытого увеличения нет |
| Исправление/отмена | Сумма/счёт/дата исправляются в канонической операции. final прикреплён к факту; отмена закрывающего факта открывает остаток. Второй активный final не допускается |
| Фиксированные | Прежний остаток и запрет превышения. Явное изменение суммы экземпляра доступно отдельно, будущий шаблон не меняется |
| Массовая оплата | Выбор нескольких→Продолжить→проверка каждой строки общим редактором→Подтвердить оплаты. Одна service.mutate/seal/CAS/IDB запись; вся группа либо ни одной операции. Банковские автоплатежи не выбираются сами |
| Один/будущие | Условия одного экземпляра либо неоплаченные условия с указанной исходной даты расписания. Периоды с историей фактов сохраняются. Исходная регулярность и якорь не сдвигаются |
| Перенести | Отдельная dueDate; стабильный ID по исходной дате, прежние факты/остаток/история. Перенос через месяц не дублирует событие |
| Месячная пауза | Пропуск выбранного неоплаченного экземпляра, не перенос. Исключён из due/forecast, виден в календаре. При активной частичной оплате заблокирован с объяснением; можно возобновить пропущенный экземпляр |
| Бессрочная пауза | Существующие интервалы сохранены, включая будущие неоплаченные экземпляры с ручными правками; частичные/ранее возникшие долги остаются; нет начисления пропущенного задним числом |
| Календарь | Реальные события выбранного месяца, состояния неоплаченного/частичного/оплаченного/пропущенного/перенесённого; тот же экран деталей, чтение без записи |
| Банковский способ | Предполагаемый счёт, известная доступная сумма и явная будущая оценка. Не прошло/неизвестно — только метаданные; успех — только реальный канонический расход. Позднее подтверждение относится к тому же событию |

Общие формы, редакторы, карточки операций, guard, контекст плана и навигация сохранены. Новые стили ограничены `.payment-calendar`; прежние правила/цвета/токены byte-identical. Массовый редактор возвращает введённые данные в проверку группы; случайный возврат из изменённой группы предлагает продолжить либо явно отказаться, без скрытого списания.

Существующая команда изменения шаблона сохранена: смена его первой даты/регулярности при уже оплаченных будущих сроках остаётся защищена от неоднозначного пересоздания. Новые команды одного/будущих меняют условия, сохраняя исходную регулярность; перенос меняет один срок.

Пакеты P2/долги/цели/лимиты/отчёты/облака/биометрия не разрабатывались. Нет публикации, банковских API, аналитики или сброса пользовательских данных.

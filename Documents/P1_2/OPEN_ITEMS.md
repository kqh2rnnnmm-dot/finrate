# P1.2 — открытые пункты и границы

- **NEEDS-DEVICE:** настоящий iPhone Safari/PWA: клавиатура, safe area/поворот/крупный текст, возврат из фона, файлы, холодный офлайн и PIN. Прежнее принятие A2/A3 без устройства и объединение P1.1 не считаются аппаратными тестами.
- Новые команды «Только этот платёж»/«Этот и будущие» сохраняют регулярность; вторая меняет неоплаченные условия с указанной исходной даты расписания. Уже связанные с фактами периоды сохраняют собственные условия. Смена глобальной первой даты/частоты при досрочно оплаченных будущих сроках остаётся безопасно отклоняемым неоднозначным случаем; автоматическое пересоздание таких периодов не вводилось.
- «Приостановить на этот месяц» пропускает именно выбранный экземпляр. Для недельного шаблона другие сроки этого месяца продолжаются; это прямо указано в подтверждении. Частично оплаченный остаток скрыть нельзя.
- Массовая группа — до200 выбранных обязательств; календарный запрос и persisted occurrence/link коллекции сохраняют ограничение20000. Превышение не усекает историю и не проводит половину группы: операция отклоняется. Экстремальный масштаб — отдельная задача.
- Группа проверки хранит незаписанные правки в открытой сессии и защищает случайный возврат. Обещания сохранения процесса после принудительного завершения iOS нет; для одиночной операции остаются прежние черновики. Приёмка фонового поведения открыта.
- Возврат денег остаётся отдельным B1-фактом и не отменяет исходное исполнение платежа автоматически. Кредитное погашение — прежний перевод, не новый расход-план.
- Старый P1.1 не понимает новые optional поля и может отказать в открытии. Для отката нужны код4ac42ea и собственная внешняя копия до P1.2. Никакого автоматического downgrade/удаления данных.
- npm audit:7 прежних dev/build advisories (4moderate,3low), high/critical0; runtime Dexie не затронут. Зависимости не менялись. Повторный разбор до следующего релиза либо05.12.2026; принудительный audit fix не выполнялся.
- Старые отдельные замечания G1/заметок/биометрии этим пакетом не закрываются.

Первый общий прогон A2/WebKit зафиксировал тайм-аут появления PIN во второй офлайн-вкладке до финального сброса. Исходный отказ и адресная проверка сохранены в TEST_REPORT; результат не скрывается и не приравнивается к аппаратной проверке.

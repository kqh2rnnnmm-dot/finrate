# P2 — реализованные изменения

Сборка `p2-debts01`, версия `0.3.12-p2`. Основа: main `d1a415a3558bdb348ddf29353398090c87367538`. Отдельная ветка `codex/p2-personal-debts`; без merge, публикации и сброса пользовательских данных.

- Раздел дополнительного меню «Долги»: «Я должен», «Мне должны», текущие записи и архив, поиск, контекстное меню, показатель Главной.
- Два способа создания. Старое обязательство не проводит деньги; передача сейчас создаёт единственную `loan-in/out` в существующих «Операциях».
- Частичные/полные возвраты через `repayment-in/out`, собственный денежный счёт, дата, примечание. Сумма остатка выводится из действующих фактов, не хранится вторым денежным журналом.
- Общая карточка операции умеет узко редактировать связанные долговые факты. Отмена/исправление сохраняет прежние значения в существующем аудите; остаток пересчитывается, повторно открытый долг выходит из архива.
- Проверки переплаты, направления при наличии фактов, даты возникновения, stale edit, повторного ID, повторного tap. Открытые и отменённые исходные займы не архивируются как погашенные.
- Явная привязка несвязанного канонического займа/возврата без второй проводки. Исторические внешние переводы не меняются.
- Датированные «Я должен» отображаются в «К оплате» отдельным источником «Возврат долга». В expense-группу P1.2 не включаются. Без даты — только собственный список и единичный учёт в «Все долги», без выдуманного срока в UI.
- В прогнозе добавлен только неоплаченный остаток соответствующего горизонта. «Мне должны» не становятся плановым доходом.
- Совпадение остатка/срока с обычным планом, кредитным обязательством или другим личным долгом требует проверки и явного подтверждения раздельного учёта. Обратная очередность создания плана также проверяется; поздние совпадения видны в карточке/«Свободно»/Главной. Автосвязывания нет.
- Формы используют существующие поверхности, поля сумм/дат/заметок/счетов, guard и зашифрованные черновики. Чтение заметки отдельно от редактирования. Исправлены выявленные узкие места собственной карточной раскладки на 320 px, двумя правилами только для собственных списков долгов: minmax(0,1fr), min-width:0 и --peer-gap. Старые CSS-правила не изменены.
- История долгов включена в существующую «Историю изменений» и открывает ту же карточку. Отдельный журнал денег не создан.
- Optional `debts.version=1` добавлен внутрь шифруемого документа. A2 расширен только известным полем; незнакомые поля по-прежнему блокируют очистку.

Не менялись SCHEMA=5, backup/1, AES-GCM, DEK/слоты, IndexedDB, пароль/PIN, B1-кредитки, планируемые доходы, scheduled-payments P1.2, навигационные/модальные механизмы, редактор заметок и прежние стили. Узкие добавочные hooks model/operations/planning проверяет `verify-delivery`: после удаления разрешённых hooks прежний код совпадает с main по SHA.

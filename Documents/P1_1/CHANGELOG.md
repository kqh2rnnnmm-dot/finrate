# P1.1 — реализованные изменения

Основа main `597b2086b7ab3826f14777bc2addecd96dc5b7e3`, A3/PR8 объединён. Ветка `codex/p1-1-scheduled-payments`; сборка `p1-1-payments01`, версия `0.3.10-p1.1`. P1.1 ещё не принят владельцем.

- Три представления существующей вкладки: «Запланированные», «К оплате», «Оплаченные»; выбор периода в двух последних.
- Создание разового, еженедельного, ежемесячного и ежегодного плана; фиксированная сумма/переменный ориентир, категория/подкатегория, счёт, дата, ручная оплата/банковский автоплатёж как пометка.
- Версии будущих условий со следующего дня. Текущие/просроченные и ранее оплаченные экземпляры сохраняются. Пауза бессрочная; возобновление пропускает даты паузы, сохраняя календарный якорь.
- Подтверждение через существующий редактор расхода: реальная сумма, дата, счёт, категории/split, примечание, черновик. Одна оплата — один обычный расход и ссылка. Части уменьшают остаток; повторный запрос не проводит его повторно.
- «Оплаченные» открывает действующую карточку операции: исправление/отмена пересчитывает остаток. Отменённые записи видны с явной пометкой; журнал не дублируется.
- «Свободно» учитывает только непогашенную часть плана в горизонте, кредитный долг поступает из прежнего creditLedger. Погашение кредитки остаётся обычным переводом B1.
- Optional payments/version1 внутри прежнего зашифрованного SCHEMA5. Старые документы читаются без записи defaults. Нет нового хранилища, миграции, DEK или протокола копии.
- A2 учитывает планы/снимки/связи в предупреждении и удаляет их во всех трёх режимах. Частичные режимы сохраняют принятую защиту, полный сброс — прежнюю механику A2. Экспорт/восстановление включают новую сущность.

Новых стилей, токенов, финансовых функций следующих этапов, облака или биометрии нет. В CSS/контекстном компоненте добавлен только новый владелец существующего долгого нажатия.

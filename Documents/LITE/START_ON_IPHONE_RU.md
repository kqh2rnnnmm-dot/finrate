# FinRate Lite — запуск на iPhone

Версия 0.1.0, сборка lite-test01. Статические файлы собраны заранее. Приложение не опубликовано; HTTPS-адреса пока нет. В архиве нет финансовой базы и копий. Используйте только вымышленные данные до завершения приёмки.

## Размещение после вашего отдельного согласия

Нужен **отдельный HTTPS-сайт**, не каталог действующего Full. Место размещения ещё не выбрано. Если у вас уже есть статический HTTPS-хостинг, загрузите в корень отдельного тестового сайта содержимое `FinRate_Lite_iPhone_Test_0.1.0_lite-test01.zip`. В корне должны оказаться index.html и остальные семь файлов, без дополнительного вложенного каталога.

Вариант ручной загрузки, если вы сами выберете Netlify и у вас есть доступ:

1. На компьютере скачайте готовый ZIP и распакуйте его в папку.
2. Откройте https://app.netlify.com/drop в своём аккаунте. Если аккаунта нет, сначала выберите подходящий вам хостинг; автоматически аккаунт не создавался.
3. Перетащите распакованную папку с index.html в область загрузки. Это действие **публикует сайт** — выполняйте только если согласны на тестовую публикацию.
4. Откройте выданную ссылку вида https://…netlify.app. Убедитесь, что видны **FinRate Lite / lite-test01**, а не Full. Запишите точный URL.
5. Отправьте этот URL себе на iPhone. Архив, файлы пароля, recovery и финансовые копии на хостинг не загружайте.

Для другого хостинга нужны MIME: .js → application/javascript, .css → text/css, .webmanifest → application/manifest+json, .png → image/png. Не включайте перенаправление всех отсутствующих ресурсов в HTML. Сохраните все файлы в одной папке; дополнительные внешние библиотеки не нужны. Если уже установлен корневой SW Full, этот origin использовать нельзя.

## Установка

1. Откройте HTTPS-ссылку в **Safari** на iPhone 11 / iOS 16.6.1.
2. Нажмите «Поделиться» → «На экран “Домой”» → «Добавить».
3. Откройте FinRate Lite с нового значка. Создайте пароль минимум 12 символов и сохраните ключ восстановления отдельно.
4. Пройдите начальную настройку. Для сценария из чек-листа введите остаток 25 000, на шаге первого дохода оставьте 0 и продолжите со стартовым шаблоном.
5. Выполните IPHONE_CHECKLIST_RU.md. В настройках можно включить PIN и выгрузить защищённую копию в «Файлы».

ZIP и локальный index.html не являются способом установки PWA. Адрес среды разработки не подходит для телефона.

## Сохранность и обновления

Закрытие/перезагрузка не сбрасывают профиль, но Safari/система могут удалить локальное хранилище. Регулярно сохраняйте копию в «Файлы» и проверяйте восстановление с паролем и recovery в отдельном чистом профиле. PIN действует на устройстве, в копию не входит. Облака/Face ID нет.

Офлайн-режим доступен после первого успешного открытия и загрузки оболочки по сети. Закрытая PWA не выполняет месячные операции по таймеру. Для обновления загрузите полный новый набор файлов на тот же тестовый сайт, закройте все его вкладки/PWA и откройте снова. Не очищайте данные сайта ради обновления. Контрольная сумма сборки — в SHA256SUMS.txt.

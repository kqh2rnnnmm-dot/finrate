Chromium путь: чистый профиль → пароль/recovery → остаток → первый доход пропустить → настройка шаблона → доход«Да» → доход«Нет» → manual → родитель/подкатегория → расход → preview → вопрос над карточкой → месяц → смена шага при preview/отмена → защита/возврат → отчёты → reload → backup → независимое восстановление → offline reload. Без фиктивной базы в приложении. Тестовый секрет и копия не включены в публичный ZIP.

Первые прогоны нашли и исправили: передачу PointerEvent вместо фильтра конверта в категориях; отсутствие offline fallback для корня сайта; потерю preview при сохранении шага. В тестовом Chromium устранён single-process runtime crash при создании второго профиля. После исправлений итоговый Chromium PASS. Статическая проверка учитывает, что Dexie содержит диагностические URL/регулярное выражение для localhost; это не ссылки на ресурсы разработчика и не сетевые запросы приложения.

Полная карта **L-01…40, M01…48, T01…30** находится в ACCEPTANCE_MATRIX.md. Не все строки закрыты полностью: явно отмечены PARTIAL и NOT RUN. Особенно остаются реальный многовкладочный stress, все варианты Back/клавиатуры/длинных названий, обновление между версиями и аппаратная приёмка.

# FinRate Lite — Work iOS02, 13.11.2026

Новое прямое поручение владельца: переработать интерфейс в Work по интерактивным примерам и Apple HIG, убрать обязательный пароль/PIN для текущей тестовой Lite, сделать отчёты по выбранным параметрам, настройки отдельными экранами с закреплённым заголовком, исключить горизонтальное гуляние страницы. Это решение выше прежнего требования обязательного входа тестового Lite; к Full не относится.

## Реализация

- Отдельный стек экранов: заголовок/возврат/действие наверху, прокрутка только содержания. Ни системного dialog поверх длинной формы, ни вложенного выбора категории внутри формы.
- Три верхних раздела сохранены. Версия перенесена из постоянной шапки в настройки. Нет нижнего дубля навигации.
- Главная: доступная сумма, два вторичных остатка, доход/расход, свободные назначения, отдельный прокручиваемый список операций.
- Конверт открывается отдельным экраном; изменение процента — ещё один экран. Суммы меняются при движении. «Сохранить» открывает вопрос над редактируемой карточкой.
- Отчёты: выбор типа → параметры (период, группировка, фильтры) → явное «Показать отчёт» → результат → исходные операции. При входе результаты и все показатели сразу не показываются.
- Категории: одна система выбора, раскрытие дочерних элементов и отдельное редактирование. Сумма/заметка сохраняются при возврате из выбора. Убрана причина дубля: скрытый нативный select, который в прежней версии получал авторский display:block, более не создаётся.
- Светлая/тёмная тема, системный шрифт, мягкие поверхности, один основной акцент, без эмодзи-шестерёнок и технических auto/manual на пользовательском экране.

## Вход и старые данные

Новый профиль открывается автоматически с локальным неэкспортируемым CryptoKey. Пароля/PIN/регистрации при первом и повторном входе нет. Отдельная DB `finrate-lite-open-test-v1`; прежняя `finrate-lite-local-v1` не читается, не удаляется и не переоборачивается молча. Это тестовый режим без проверки пользователя устройства, а не эквивалент прежней парольной защиты.

Файл резервной копии шифруется отдельным паролем, который пользователь задаёт только при экспорте. Это не возвращает регистрацию или запрос пароля при запуске. Поддерживаемая прежняя копия может быть импортирована вручную с её собственным секретом; автоматический перенос старой защищённой базы не выполнен. Работа с Full не менялась.

## Основания оформления

- Apple HIG Layout: https://developer.apple.com/design/human-interface-guidelines/layout.md — иерархия, группировка, постепенное раскрытие, адаптация и safe area.
- Apple HIG Toolbars: https://developer.apple.com/design/human-interface-guidelines/toolbars — заголовок текущего представления, предсказуемые Back/Close, ограничение числа действий.
- Apple HIG Sheets: https://developer.apple.com/design/human-interface-guidelines/sheets.md — модальная задача не подменяет иерархию приложения. Выбор полноэкранного стека здесь также прямое требование владельца, а не заявление, что Apple запрещает sheets.
- AI Development Kit, feat/library-v1: design-direction@53c4f62d86fb10381c843967f7bfacfe879af92c и ux-audit@5af9d9f8c91726efe84dacb00a4eb1509f25c326 — связь наблюдений с исправлением и критериями приёмки. Проверена основа README/AGENTS. Внешние скрипты/плагины не устанавливались из этих навыков.

## Границы

Финансовый model.mjs, crypto.mjs, store.mjs и device-access.mjs прежние. Новой реализации финансовой математики нет; новый reporting.mjs строит выбранную выборку и группировки. Полная релизная приёмка исторической матрицы не объявляется закрытой этим редизайном. Реальные iPhone/Safari, VoiceOver, увеличение системного шрифта, реальная клавиатура, существующая установленная PWA при обновлении — аппаратная приёмка владельца.

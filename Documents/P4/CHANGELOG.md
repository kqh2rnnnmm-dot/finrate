# P4 — реализованные изменения

`p4-limits01` / `0.3.14-p4`, ветка `codex/p4-limits`, основа `eea169f4605a0afa155ab69c95a867ee39749fda`. Готово для ревизии; не слито/не опубликовано.

- Меню → Лимиты: активные и отключённые месячные правила, создание/чтение/правка суммы, назначения и месяца, явный архив/включение, отдельный выбор сохранённых прошлых месяцев. Другой месяц без правила пуст, автоматического переноса нет.
- Родительские/детские карточки с точными копейками, заполнением и текстовыми normal/near/reached/exceeded. Подробности открывают исходные канонические операции с суммой подходящей части split/refund, а не вторым журналом.
- Предупреждения текущего месяца после подтверждённого пересечения; 80% по умолчанию, настройка1–99/early-off, прежние финансовые permissions/очередь. Реальную покупку лимит не блокирует.
- Существующая Home-плитка во всех трёх стилях и1–6 блоках показывает приоритет/количество состояний, без сложения вложенных денег; тап открывает текущий месяц. Настройки → Лимиты → Предупреждения.
- Общие категории/числовой редактор, guard/черновики, история, поиск, контекстное меню, возврат/скролл, темы/палитры. Новые CSS только [data-limits-ui]; старые стили/токены не меняются.
- Optional limits/version1, два зашифрованных settings-поля, валидация ссылок/ID/месяцев/целых копеек, идемпотентные ID, copy/seal/CAS, strict A2 allowlist/summary. Реальные копии и независимое восстановление прежнего формата.
- FAQ и передача следующей ACCESS-after-P4 задаче. Ни emergency login reset, ни Apple Account, ни UI-заглушек доступа здесь нет. Подготовленный будущий контракт не редактировался.

Не переписаны service/store/crypto/device-access, B1/totals/postings/credit/forecast, P1.2, P2/P3, редакторы/поверхности/навигация. Подтверждается SHA-проверкой verify-delivery, не только ручным утверждением. Рабочие публичные файлы собраны локально, это не deployment.

Ограничения: [OPEN_ITEMS](OPEN_ITEMS.md), устройство: [IPHONE_ACCEPTANCE](IPHONE_ACCEPTANCE.md), контракт: [FINANCIAL_MATRIX](FINANCIAL_MATRIX.md).

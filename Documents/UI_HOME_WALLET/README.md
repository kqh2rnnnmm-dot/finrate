# Home Wallet · визуальный эксперимент главной (11.11.2026)

## Задача и границы

Переработать визуальную иерархию главного экрана FinRate, сохранив финансовые расчёты, документы, локальное хранилище, конфигурацию блоков, поведение кнопок и настройку палитр. Реализация в рамках текущего приложения, не самостоятельный продукт. **Без слияния, публикации и действий с реальными пользовательскими данными.**

Основные источники: локальные `DESIGN.md` и UX-контракт FinRate, центральный AI Development Kit (`design-direction`, `ux-audit`, `frontend-design`, `standards/DESIGN.md` и `standards/UX.md`). Визуальный принцип — ясная иерархия и тихие системные поверхности в духе iOS, без копирования фирменных элементов Apple.

## Рассмотренные направления

1. **Wallet / спокойный системный интерфейс** — главная сумма как акцентный модуль, свободные деньги отдельно, карточки второго уровня, аккуратный контраст и фокус. Выбрано: соответствует задачам финансовой главной.
2. **Ledger / финансовая ведомость** — плотные строки и разделители, лучше для больших историй, но противоречит привычной компоновке до 6 карточек.
3. **Mosaic / разноцветные виджеты** — заметнее, но отвлекает от точных финансовых сумм и конкурирует с пользовательскими палитрами.

## Что изменено

Только `Source/src/style.css`: стили ограничены селекторами `.main-home`; два существующих блока «Фактический остаток» и «Свободные деньги» визуально разделены, усилена типографическая иерархия; карточки получили лёгкие контуры, мягкую глубину и более явные состояния клавиатурного фокуса; параметры адаптированы для коротких экранов. Разные палитры, три представления плиток, их количество (1–6), финансовая семантика и механика кликов сохранены на уровне исходного кода. Не добавлено зависимостей, удалённых запросов, аналитики.

## Приёмка

- 1–6 блоков × `numbers/details/rows` × `light/dark` × ширины/высоты 320×568, 375×844, 390×844, 430×844 и 844×390: нет горизонтального скролла, перекрытия заголовков/значений и наезда на нижний док.
- Точная сумма доступна в aria-label и по существующему нажатию; только внешний вид значения изменяется.
- Каждая плитка открывает прежний экран, настройка количества/вида/палитры сохраняется.
- Кнопки доступнее с клавиатуры; при reduced motion нет лишних движений.
- Светлая/тёмная и нейтральная/цветная темы, все три пользовательские палитры для двух крупных сумм.
- Финансовые результаты до/после совпадают на тестовой базе. Проверить вручную на iPhone перед публикацией.

- **PASS, только дизайн-макет:** автономный синтетический HTML-макет открылся в Chromium, 6 плиток, светлая/тёмная темы, без ошибок JavaScript и переполнения самого макета; не является запущенным FinRate.
- **NOT RUN:** `npm run build`, `npm test`, `npm run check:release` и весь браузерный матричный тест настоящего приложения: полный приватный проект не был развёрнут в локальной среде тестирования этого чата.

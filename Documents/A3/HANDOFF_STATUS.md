## Формулировки, которые нельзя путать
- «Изменить основной пароль» — изменить секрет для текущего password slot; не обещать отзыв старых копий/DEK.
- «Открывать без проверки» — **локальный режим входа**, не удаление шифрования и не новый способ экспорта без пароля.
- «Установить/Изменить/Убрать PIN» — локальный быстрый вход, он не открывает защищённый файл.
- «Биометрия» — условная возможность, только при доказанной привязке к ключу расшифровки. Системный prompt или проверка WebAuthn public-key сам по себе недостаточен.

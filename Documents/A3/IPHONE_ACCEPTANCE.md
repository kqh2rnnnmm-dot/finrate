# A3 · аппаратная приёмка

**Все пункты NOT VERIFIED ON IPHONE.** Автотесты Chromium/WebKit/Linux и модель VisualViewport/часов не заменяют Safari/установленную PWA. A2 принят владельцем без устройства; его аппаратная проверка остаётся отложенной.

Испытания выполнять после отдельно согласованного размещения **a3-access01 / 0.3.9-a3** на изолированном тестовом origin, только с вымышленными данными. Эта ветка ничего не публикует. Не удалять действующую PWA, её базу/иконку или данные Safari. Не присылать пароль, PIN, recovery, файл базы или снимок с ними.

Face ID/Touch ID как самостоятельного входа FinRate **нет**. Отсутствие кнопки — ожидаемый результат этой сборки. Биометрический prompt системного менеджера паролей относится к AutoFill. Для PRF нужен отдельный согласованный аппаратный прототип; не экспериментировать с действующим dataset. [Заключение](BIOMETRY_FEASIBILITY.md).

Зафиксировать только build ID, модель/iOS, Safari или PWA, палитру/тему, шаг и результат. Снимки делать на пустых полях/после маскирования. Если обнаружен дефект — не сбрасывать данные для «исправления», сохранить независимую пригодную копию и описать шаги.

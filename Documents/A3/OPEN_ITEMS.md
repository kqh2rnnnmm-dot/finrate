# A3 · открытые пункты и ограничения

| Пункт | Статус |
|---|---|
| Face ID/Touch ID через PRF | **NEEDS-DEVICE**, не включён. Нет подтверждённого credential-bound unlock key/lifecycle в установленной iPhone PWA. [Отдельный отчёт](BIOMETRY_FEASIBILITY.md) |
| Системный AutoFill/сохранение/обновление «Пароли» | Стандартные HTML-подсказки реализованы; нативный prompt и различия Safari/PWA **NOT VERIFIED ON IPHONE**. Recovery/PIN off — подсказка, браузер/менеджер может применять собственные правила |
| Аппаратные таймеры, переключатель приложений, клавиатура/VoiceOver | DEVICE-REQUIRED. Нельзя гарантировать фоновые события/процесс/снимок ОС. [Чек-лист](IPHONE_ACCEPTANCE.md) |
| A2 F/C/A и восстановление на iPhone | A2 принят владельцем без проверки. Автотесты сохранены, аппаратная приёмка отложена |
| A1-F02: ранее раскрытый DEK | Документированная граница. Ротация/отзыв исторического ключа не реализуются без отдельного архитектурного согласия |
| PIN против доступа к профилю/JS того же origin | Короткий локальный механизм и лимит приложения; не Secure Enclave/не абсолютная защита от offline-перебора |
| G1 Issue #5 | Исправления A2 сохранены; аппаратная оценка положения/жеста остаётся открытой. A3 не переписывает уведомления |
| C1/D1 заметки | Конкретный остаточный случай iPhone не воспроизведён, не закрыт A3 |
| Системная accessory-панель iOS | Не скрывается нестандартными способами |
| npm dev/build advisories A1 | Отдельный разбор достижимости/совместимых обновлений; нет audit fix --force. Актуальная сводка — TEST_REPORT |
| Нейтральные token-combinations на menu-selected | Существующие низкие сочетания 2.48–4.47, вне поверхностей формы доступа; сохранены без редизайна. Измерения и предел вывода — TEST_REPORT |
| Биометрия на ПК/всех iPhone | Не заявляется. Наличие platform API не является проверкой реальной функции |

Слияние/публикация требуют отдельного решения владельца. При будущем merge сохранить предыдущий main резервной веткой. A3 не создаёт сервер/новый домен, не удаляет рабочие данные и не меняет криптографическую архитектуру.

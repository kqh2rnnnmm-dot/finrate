# Заметки: сквозная проверка A2

Оставшийся кейс владельца после D1 в архиве не задан точной последовательностью. Вопрос о воспроизведении задан; до уточнения замечание **не закрывается**. Новый дизайн или собственный редактор не добавлены.

| Сценарий | Общий владелец / вызывающий модуль | Проверка |
|---|---|---|
| Примечание расхода/дохода/перевода/возврата, черновик и изменение операции | field-editor + focus + ui | ввод до 500, абзацы, длинное слово/смешанный текст, отмена/принятие поля отдельно от записи, unsaved guards |
| Просмотр полного примечания операции | field-editor.view из ui | без клавиатуры, отдельное редактирование, возврат к карточке |
| Описание счёта, редактирование счёта | field-editor из management/focus | тот же компонент, рамка/разворачивание/лимит, родительская форма отдельно |
| Комментарии к планируемым доходам | field-editor.view из planning-ui | чтение/изменение через общий компонент, сохранение штатной мутацией |
| Полный прежний/новый текст в истории | field-editor.view из activity-ui | полный readonly текст без клавиатуры, история не превращается в редактирование старого события |
| Категории / настройки | длинных редактируемых заметок в текущей схеме нет | названия — обычные короткие поля; новые длинные поля не придуманы |

В свежем check:release выполнены D1/C1/geometry/keyboard-модели в Chromium и WebKit, включая 320/375/390/402/430 CSS px, landscape/ПК, обе темы. Дополнительный A2 UI-тест проверяет текст 500 символов с абзацами/длинным словом/латиницей, панающий VisualViewport и расширение после закрытия модельной клавиатуры. Исходные снимки «до» и A2 «после» показывают тот же редактор.

Единственное изменение `field-editor.mjs` — исключение новых форм проверки/финального подтверждения A2 из автоматического вложенного редактора. Секрет и фраза подтверждения остаются штатными полями аутентификации. Текстовое редактирование не переписано. `surfaces.mjs` при общей очистке сбрасывает ссылку на прежнюю pointer-кнопку; ввод/денежные правила не менялись.

Системная панель iOS со стрелками/галочкой принадлежит WebKit; поддерживаемого API удаления нет, обходов нет. Настоящая клавиатура, выбор позиции курсора, интерактивное скрытие, VoiceOver и оставшийся пользовательский кейс требуют Safari/PWA iPhone. Нужна короткая последовательность или запись экрана без секретов; зелёные D1-тесты не считаются закрытием неопределённого замечания.
